# 0.3.0-alpha.1：无线组控制测试版

本版基于0.2.1，代码构建与自动测试通过，不代表新增硬件路径已实测。未自动替换任何正在运行的服务，未向真实风扇或灯环下发测试指令。

## 本次实现

- 独立“风扇”页面，每个无线设备作为一个组，组内统一PWM；组级固定、CPU/GPU/水温曲线、采样点图表/表格、采样周期、平滑、回差、降速延迟及升降速限幅。
- 设备本机别名按MAC保存；原生RF Select闪灯识别命令入口，只有已确认支持的本机TL组可调用。
- 每组独立灯效配置，复用现有TL效果和上下弧分区。能力按当前组的扇数读取。
- 独立8.8灯环接口0416:8050；支持关闭/纯色/彩虹/彩虹渐变/呼吸/波浪六种自研渲染。默认不接管；未做真机颜色顺序与节奏验证，UI明确实验性。
- 8.8显示接口1CBE:A088完全交给Libre Panel，本程序不认领、不复位它。
- 冷头媒体/主题渲染移至可选进程lcl-display-host；控制daemon不再依赖lcl-media。冷头发送仍通过daemon唯一H2句柄，以免屏与泵抢设备。
- daemon与开机keeper复用相同组策略求值；源不可用时默认80%保护，紧急温控不能被低定速覆盖；曲线编辑保留输出限速状态。
- 前端配置写串行化，按编辑段合并，减少页面间并发写覆盖。旧配置保留兼容字段并在首次读取时备份。

## 支持范围

首期可写白名单：现有TL V2无线型号码27..35、1..4扇。TL120×1和TL140×3需在用户设备上确认识别及行为。
其他无线型号目前只读识别，不假装已验证。无有线系列支持。无组内单扇独立转速入口。

风扇“固定”是固定PWM，不是精确RPM闭环。真实RPM由设备延迟回报。

## 便携包使用

1. 先退出官方桌面端并确认它的控制服务不再占无线TX/RX；不要先卸载官方程序，保留回退途径。Libre Panel保持运行。
2. 先打开lcl-app.exe。此实验版不会因打开窗口而自动启动控制daemon。看界面无后台时，点击“启动后台服务”才开始接管。
3. 到设备页先对每个TL组点“识别”，确认物理组，再命名“后部排风”“底部进风”。不能从MAC排序推断位置。
4. 到风扇页给两组分别设策略并应用。组内会统一PWM。CPU温度读不到时先用固定PWM验证，不要把占用率当温度。
5. 8.8灯环先用低亮度纯色确认颜色和位置，再试动效。关闭“控制灯环”是释放接管并保持最后颜色；要熄灯应保持接管并选效果“关闭”。
6. 8.8画面继续在LP里编辑，这个测试版不会接管它。
7. 如需要原有冷头图片/GIF/主题，选好内容后手动运行lcl-display-host.exe；不用冷头屏可不运行。它只经命名管道交帧，不打开USB。

关闭GUI不等于退出控制daemon。退出接管需要从托盘退出LConnect Lite。退出后设备一般保持最后目标，恢复官方控制前确认新daemon完全退出。

## 数据与回退

仍使用原项目路径：%APPDATA%\LConnect Lite\config.toml、%ProgramData%\LConnect Lite\control.toml，以及原命名管道。
不要同时运行旧版和新版daemon。旧配置读取前创建config.toml.pre-groups.bak；程序并未进行系统服务安装/更新。
便携包中的lcl-sensord.exe只是供后续安装更新使用，当前不会替换已安装传感器服务。若系统仍装旧版sensord，登录前控制仍是旧逻辑，须待单独确认后更新；不声称新keeper已经在运行。

回退：退出新daemon后恢复备份配置，再启动原控制程序。不要把已升级的新配置交给旧版保存，以免新组策略被丢弃。

## 验证情况

- cargo test --workspace：143项单元/集成测试通过（16 core +15 daemon +22 devices +10压缩参考向量 +9 display-host +65 effects +6 media）。
- npm run check、npm run build通过；Tauri release应用可构建。
- 浏览器mock验证设备/风扇/灯环路由及设备命名。浏览器截图工具返回空图，未声称完成像素级视觉验收。
- 未做真机闪灯、独立两组调速、灯环控制和30分钟压力测试。这些是接下来验收清单，不是已完成结果。

## 构建

cargo build --release -p lcl-daemon -p lcl-sensord -p lcl-display-host

将三exe复制到app/src-tauri/binaries并加x86_64-pc-windows-msvc后缀，app下运行：

npm run check
npm exec -- tauri build --no-bundle

完整安装包脚本scripts/build-installer.ps1已纳入内容宿主，但本轮优先交付便携包，避免安装器自动修改官方服务与开机项目。
